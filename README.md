<h2 id="ai">AI</h2>

<p>
  <img src="https://img.shields.io/badge/AI-Tools-7C3AED?style=flat-square" alt="AI Tools" />
</p>

Tools for generating code, apps, designs, visuals, and other AI-powered workflows.

- [CodeRabbit](https://coderabbit.ai) — AI-powered code review tool.
- [Blink](https://blink.new) — build full-stack applications with AI.
- [IdeaHunter](https://ideahunter.today) — discover demand-backed app and micro-SaaS ideas.
- [Pomelli](https://labs.google.com/pomelli) — generate ideas, palettes, and design assets with AI.
- [Napkin](https://napkin.ai) — turn written ideas into diagrams, charts, and visuals.
- [Blueprint](https://blueprint.am) — AI assistant for hardware design and product development.
- [Dora](https://dora.run) — build and ship 3D and animated websites with AI.
- [Textlab](https://textlab.javii.tools) — text animation mockup generator.
- [Lummi](https://lummi.ai) — AI-generated images and illustrations.
- [LogoAI](https://logoai.com) — AI-powered logo and brand identity generator.

<h2 id="developer">Developer</h2>

<p>
  <img src="https://img.shields.io/badge/Developer-Tools-2563EB?style=flat-square" alt="Developer Tools" />
</p>

Resources for building, testing, prototyping, and working with software.

<h3 id="developer-utilities">Developer Utilities</h3>

- [Agent QA](https://github.com/vostride/agent-qa) — natural-language web and mobile application testing through an npm CLI and MCP server.
- [IT-Tools](https://it-tools.tech) — collection of useful online utilities for developers.
- [CSVTool](https://csvtool.com) — browser-based tools for viewing, editing, and converting CSV files.
- [123apps](https://123apps.com) — collection of online tools for editing and converting files.
- [CustomGraph](https://customgraph.com) — generate and print custom graph paper and worksheets.
- [VisuAlgo](https://visualgo.net) — visualizations of data structures and algorithms.
- [ASCII Art Archive](https://asciiart.eu/image-to-ascii) — image-to-ASCII converter and ASCII art collection.
- [TinyWow](https://tinywow.com) — free tools for PDF, image, writing, and other tasks.
- [JSON Crack](https://jsoncrack.com) — visualize JSON and YAML as interactive graphs.
- [DevDocs](https://devdocs.io) — searchable documentation for programming languages and APIs.
- [Kaggle Learn](https://kaggle.com/learn) — interactive courses for Python, SQL, data science, and more.
- [Pydle](https://pydle.net) — Wordle-style game for Python concepts.
- [PyUiBuilder](https://pyuibuilder.com) — drag-and-drop GUI builder for Python applications.
- [Responsively](https://responsively.app) — responsive web development and testing tool.
- [Cubic Bezier](https://cubic-bezier.com) — interactive cubic-bezier timing-function editor.
- [CSS-Tricks Almanac](https://css-tricks.com/almanac/) — reference for CSS properties and web development.

<h3 id="apis--backend">APIs & Backend</h3>

Services and APIs useful for building applications.

- [Tally](https://tally.so) — simple form builder for collecting submissions.
- [Resend](https://resend.com) — email API for developers.
- [Supabase](https://supabase.com) — open-source backend platform built around PostgreSQL.
- [REST Countries](https://restcountries.com) — API providing information about countries around the world.

<h3 id="maps">Maps</h3>

Mapping tools and resources for web applications.

- [MapCN](https://mapcn.vercel.app) — customizable map components for modern web applications.
- [MapCN GitHub Repository](https://github.com/AnmolSaini16/mapcn) — source repository for MapCN.

<h3 id="testing--prototyping">Testing & Prototyping</h3>

Tools for testing interfaces, experimenting with hardware, and rapid prototyping.

- [Wokwi](https://wokwi.com) — online electronics simulator for Arduino, ESP32, Raspberry Pi Pico, and more.
- [Tinkercad](https://tinkercad.com) — browser-based 3D design and electronics platform.

<h2 id="ui--design">UI & Design</h2>

<p>
  <img src="https://img.shields.io/badge/UI_%26_Design-EA580C?style=flat-square" alt="UI & Design" />
</p>

Resources for designing interfaces, finding inspiration, creating visual assets, and building better websites.

<h3 id="ui-components">UI Components</h3>

Component libraries and ready-to-use interface resources.

- [daisyUI](https://daisyui.com) — component library built on top of Tailwind CSS.
- [Material UI](https://mui.com) — React component library based on Material Design.
- [shadcn/ui](https://ui.shadcn.com) — accessible and customizable React components.
- [React Bits](https://reactbits.dev) — creative React components for modern interfaces.
- [Uiverse](https://uiverse.io) — community-made UI elements with copy-paste code.
- [Aceternity UI](https://ui.aceternity.com) — animated UI components built with Tailwind and Motion.
- [CSS Loaders](https://css-loaders.com) — copy-paste CSS loaders and spinners.
- [Magic UI](https://magicui.design) — animated React components for modern interfaces.
- [HyperUI](https://hyperui.dev) — free Tailwind CSS components.
- [21st.dev](https://21st.dev) — community-driven React and Tailwind components.
- [OriginKit](https://originkit.dev) — UI resources and components for modern web interfaces.

<h3 id="design-inspiration">Design Inspiration</h3>

Collections of websites, products, portfolios, and interfaces worth studying.

- [Awwwards](https://awwwards.com) — showcase and awards platform for exceptional web design.
- [Land-book](https://land-book.com) — curated collection of website design inspiration.
- [Dribbble](https://dribbble.com) — community for discovering and sharing design work.
- [Godly](https://godly.website) — curated collection of exceptional web design.
- [Design Vault](https://designvault.io) — curated library of UX/UI design inspiration.
- [Shortcuts.design](https://shortcuts.design) — keyboard shortcuts for design tools.
- [Refero](https://refero.design) — product UI and design research library.
- [httpster.net](https://httpster.net) — gallery of well-designed websites.
- [Curated.design](https://curated.design) — filterable design inspiration gallery.
- [Hoverstat](https://hoverstat.es) — showcase of unusual interactive web design.
- [Unsection](https://unsection.com) — curated single-section website examples.
- [Page Flows](https://pageflows.com) — real product user-flow recordings.
- [Cosmos](https://cosmos.so) — visual bookmarking and curation platform.
- [Shots.so](https://shots.so) — create device and browser mockups from screenshots.
- [Reelfolio](https://reelfolio.io) — turn screenshots into polished showreel videos.
- [Cofolios](https://cofolios.com) — real design intern and portfolio pages from top tech companies.
- [Islands](https://islands.study) — curated visual resource for discovering websites and design.

<h3 id="colors">Colors</h3>

Color palettes, generators, and visual tools.

- [Realtime Colors](https://realtimecolors.com) — visualize and test color palettes on realistic website layouts.
- [Haikei](https://haikei.app) — generate SVG backgrounds, blobs, waves, and other visual assets.
- [Chromateque](https://chromateque.netlify.app) — curated color and gradient inspiration tool.
- [Colors Visualizer](https://colors-visualizer.vercel.app) — create and preview color palettes in real time.
- [Glassmorphism](https://glassmorphism.com) — glassmorphism CSS generator.
- [Glassmorphism Generator](https://hype4.academy/tools/glassmorphism-generator) — visual glassmorphism generator with adjustable blur, refraction, and depth.

<h3 id="animation--motion">Animation & Motion</h3>

Animation libraries, motion tools, and interactive visual resources.

- [Anime.js](https://animejs.com) — lightweight JavaScript animation library.
- [Jitter](https://jitter.video) — motion design and animation tool.
- [Motion Sites](https://motionsites.ai) — collection and inspiration for motion-focused websites.
- [Paper Animator](https://paperanimator.com) — create animated paper-style visual effects.
- [3dsvg](https://3dsvg.design) — turn SVG graphics into 3D animated visuals.
- [60 FPS](https://60fps.design) — resource for learning smooth, high-performance web animations.
- [Unicorn Studio](https://unicorn.studio) — create WebGL motion and interactions without code.

<h3 id="fonts--typography">Fonts & Typography</h3>

Tools for finding and pairing typefaces.

- [Fontjoy](https://fontjoy.com) — generate font pairings using machine learning.

<h3 id="design-tools">Design Tools</h3>

Tools for creating, editing, and managing visual assets.

- [Bioicons](https://bioicons.com) — free science icons for figures and presentations.
- [BrightIcons](https://brighticons.netlify.app) — icon browser and resource for UI projects.
- [SvgAPI](https://svgapi.com) — large collection of free SVG icons.
- [Brand Bird](https://brandbird.app) — create visuals for branding and social media.
- [Unicorn Studio](https://unicorn.studio) — create WebGL motion and interactions without code.
- [unDraw](https://undraw.co) — open-source illustrations for any idea, customizable colors.
